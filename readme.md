# A step by step guide to creating a android app with a modern architecture using Kotlin and Android Studio

My learning progress on `how to create an Android app with a modern architecture using Kotlin and Android Studio`.

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.
